1. Visit: `https://vatsalvarma.github.io/F-G-Test-/`
2. Wait 2 minutes for deployment to complete
3. Look for **"Install App"** button in the header (next to location)

### On Android (Chrome):
1. Open the app in Chrome
2. Tap the **"Install App"** button in the header
3. Or tap the 3-dot menu → "Install app" or "Add to Home screen"
4. Confirm installation

### On iOS (Safari):
1. Open the app in Safari
2. Tap the Share button (square with arrow)
3. Scroll down and tap "Add to Home Screen"
4. Tap "Add"

## 🔍 Why PWA Install Might Not Show Immediately

### Browser Requirements:
- **HTTPS Required** ✅ (GitHub Pages uses HTTPS)
- **Valid Manifest** ✅ (Fixed with proper scope and icons)
- **Service Worker** ✅ (Generated by Vite PWA plugin)
- **User Engagement**: Some browsers require 30 seconds of usage first

### Chrome/Edge Install Criteria:
✅ Web app is not already installed
✅ Meets user engagement heuristic (30 seconds on site)
✅ Includes a web app manifest with:
   - `name` or `short_name`
   - `icons` (including 192px and 512px)
   - `start_url`
   - `display: standalone`

✅ Served over HTTPS
✅ Has registered service worker with fetch event

## 🧪 How to Force Install Prompt (Testing)

### Chrome DevTools:
1. Open DevTools (F12)
2. Go to **Application** tab
3. Click **Manifest** in left sidebar
4. Verify manifest loads correctly
5. Click **Service Workers** 
6. Verify SW is activated
7. Go to **Application** → **Install** button at top
8. Click to trigger install

### Clear Cache & Retry:
1. Open DevTools (F12)
2. Right-click the refresh button
3. Select "Empty Cache and Hard Reload"
4. Wait 30 seconds on the page
5. Install prompt should appear

## 🐛 Troubleshooting

**If install button doesn't appear:**
1. Open DevTools Console (F12)
2. Check for errors
3. Go to Application → Manifest (should load without errors)
4. Go to Application → Service Workers (should show active SW)
5. Make sure you're on HTTPS (GitHub Pages)
6. Try incognito mode
7. Wait 30 seconds and interact with the page

**Force refresh the page:**
- Windows: `Ctrl + Shift + R`
- Mac: `Cmd + Shift + R`
